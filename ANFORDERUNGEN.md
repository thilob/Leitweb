A1: Es soll eine Leitstellen-Webanwendung entstehen. Die Anwendung soll aus einem oder mehreren Docker-Containern entstehen, die im weiteren Verlauf auch zu einem Kubernetescluster gewandelt werden können.
A2: Die Daten sollen möglichst gut strukturiert vorgehalten werden. Der Zugriff auf die Daten soll möglichst offen durchgeführt werden können.
A3: Die Anwendung soll ein RBAC enthalten, so dass verschiedene Funktionen verschieden reglementiert werden können.
